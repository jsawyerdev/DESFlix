UI design references

This design system was revised from an earlier, decorative-gradient version after review flagged it as vibe-coded — color with no semantic meaning, and no way to tell an observed number from an estimate. The revision is grounded in two researched references rather than invented from scratch:

  • Netflix's public dark-theme conventions — near-black background family (#141414/#1F1F1F), white reserved for the one primary label per surface, muted grey secondary text (#B3B3B3), ~8px corner radius, edge-clipped horizontal carousels. Source: Netflix Design System — Colors, Typography & Tokens, Netflix Color Palette reference.
  • Evidence-grade dashboard practice — progressive disclosure to manage cognitive load, explicit "last updated" freshness timestamps, and documented source lineage to establish trust. Source: UXPin, Dashboard Design Principles, Pencil & Paper, Dashboard UX Pattern Analysis.

DESFlix does not use Netflix's actual brand red or the Netflix Sans typeface (proprietary) — only the structural/tonal conventions above, applied to this product's own accent color and a system font stack. Component-level rules this system enforces: color used only for semantic state (pass/fail/pending/info, never decoration); every score or badge either plainly observed or explicitly marked estimated; every data-bearing screen carries a freshness timestamp; AI-origin disclosure shown as a lineage trail, not a single opaque badge; cards used only for actual decision units (what to watch), tables used for anything comparative (rankings, pipeline stages, job history).

Visual design is placeholder (flat muted tone + hatch stands in for real key art/thumbnails — deliberately not a gradient, so it reads as "no art yet" rather than a fake decorative finish). The color system, spacing scale, and evidence/freshness/lineage components are the reusable part of this mockup set, not the specific copy or numbers shown.
