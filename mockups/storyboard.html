End-to-end storyboard

One title's path from script to viewer payout to advertiser placement, frame by frame. Each frame names the doc section it implements so the visual sequence and the written dataflows never drift apart. This is a journey sketch, not a fifth persona screen — it exists to check the other six mockups actually compose into one coherent flow.

Where this exposes a gap

Frame 02's node operator doesn't reappear until payout — there's no frame showing the operator learning a job was assigned or disputed in real time. That's a legitimate gap in this storyboard (the Node Dashboard mockup covers it after the fact, not during), not a claim that the product doesn't need it. Left open rather than papered over.
